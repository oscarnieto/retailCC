# Logos de inquilinos (carrusel)

Sube aquí los logos en **PNG con fondo transparente**, con estos nombres exactos
(todo en minúsculas). Se escalan solos a ~40 px de alto en el carrusel:

| Inquilino     | Archivo                          |
| ------------- | -------------------------------- |
| Worten        | `worten.png`                     |
| Sport Zone    | `sport-zone.png`                 |
| The Food Co.  | `the-food-co.png`                |
| C&A           | `ca.png`                         |
| Kiabi         | `kiabi.png`                      |

Si falta algún archivo, el carrusel muestra el nombre del inquilino como texto
(fallback automático). Las rutas se configuran en `js/content.js` → `tenants.items`.
